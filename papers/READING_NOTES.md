## 1. Yin et al., *Multi-Channel CNN-Based Open-Set RF Fingerprint Identification for LTE Devices*
IEEE TCCN 10(5), 2024, DOI 10.1109/TCCN.2024.3391293。

**问题设定**：10 台 LTE 手机，6 台已知 / 4 台未知；开集 = 先判"是否未知"，再分类。
数据：LOS/NLOS 两个场景各 5 / 2 个采集位置，6535 + 5030 条前导。

**方法**
1. 前导检测（滑窗能量比）→ 粗同步（CP 与尾部相关）→ **精同步（与 64 个标准前导做频域相关，先定前导号 v′ 再细化起点）**。
2. 切出三段：**transient-on（起点前 50 点）、modulation、transient-off（终点后 50 点）**。
   理由写得很直白：瞬态段不到 100 点，调制段 14450 点，放在同一张图里瞬态会被压掉。
3. 每段生成一张 **DCTF**：`D[n] = y[n]·y*[n+L_DF]`，再把复数点映射成二维密度直方图。
   差分操作把载波相位/CFO 消掉，只留下幅度与相位轨迹差异。
4. **MCCNN**：三路卷积分支（每段一张图）→ 展平拼接 → 三层 FC → z（维度 = 类别数 K）→ softmax。
5. **损失**：`L = L_CE + α·L_MM`，α=0.5，其中
   `L_MM = d_max / d_min`，`d_max` = 各类样本到类均值距离的最大值的平均，`d_min` = 最近两个类均值的距离。
   ——这是"类内压实 + 类间拉开"的比值形式。
6. **开集判决**：在 K 维 z 上算**每类马氏距离** `d_j`，相似度 `S_f = 1/min_j d_j`，`S_f < λ` 判未知。

**结果**：未知检测 AUC 0.9817、EER 0.0545；已知分类 98.70%（LOS）/ 89.40%（NLOS）。
加 maxmin 后未知检测变好，但**已知分类从 98.45% 掉到 97.15%**。

**可迁移的三点**
- 马氏距离是在 **K 维**（6 维）空间算的，不是在高维 embedding 上。这样协方差良态。
  我现在的 `pcmaha` 是 512 维降 64 维 PCA，条件数差得多。
- maxmin 损失是一个现成的、比我"中心损失"更完整的开集正则（我只压了类内，没管类间）。
- 他们对**瞬态**的处理（单独切段、单独成像）与我的观察一致：我把瞬态裁掉了。

**局限**
- 阈值 λ 怎么定没写；EER/AUC 都是阈值无关指标，回避了这个问题。
- maxmin 会牺牲闭集精度，作者只做定性解释（"一个模型要兼顾两者"）。

## 2. Long et al., *Open-Set UAV Signal Identification Using Learnable Embeddings and Energy-Based Inference*
Drones 10(1):36, 2026。

**问题设定**：10 台同型号 DJI 无人机，**每台分 4 个不同时段采集**；已知 4 类、未知 1–6 类，
openness 扫描；SNR 0 dB 为主。

**方法（GE-OSR）**
1. 前端：频率条件化时序调制（FCTM，用频谱统计量生成 γ/β 做仿射）+ 卷积-Transformer 并行块。
2. **可学习类嵌入** `c_1..c_K`，从标准高斯采样后归一化到单位球。
3. **DCEL**（双约束嵌入损失）：
   - 类内 `L_intra = log(1 + Σ_i e^{−α(sim(z_i,c_k)−δ)})`
   - 类间 `L_inter = log(1 + Σ_{i:y_i≠k} e^{α(sim(z_i,c_k)+δ)})`
   - α=32，δ=0.1
4. **FEAL**（自由能对齐）：能量定义在余弦距离上
   `E(z) = −(1/T)·log Σ_k e^{−T·D(z,c_k)}`（平滑最小值），
   `L_FEA = mean((E(z) − E0)²)`，E0=−0.1，T=10。
   **关键是它只用已知样本**，不需要未知样本就能塑造能量边界。
5. 判决：训练中 EMA 统计能量的 μ、σ，阈值 `τ = μ + βσ`（β=0.2）。

**结果**：4 已知 + 6 未知时 AUROC 96.62%、OSCR 95.98%。
消融（4 已知 6 未知，5 次重复）：

| 配置 | AUROC | OSCR |
|---|---:|---:|
| 基线（无 FCTM/DCEL/FEAL） | 70.09 | 62.35 |
| +FCTM | 86.38 | 84.15 |
| +FCTM +DCEL | 91.22 | 89.69 |
| +FCTM +DCEL +FEAL | 96.62 | 95.98 |

**可迁移的三点**
- **每个设备采 4 个时段**，论文明确写了这是为了"避免单会话效应"。
  这正是我数据的最大缺陷——我们有意识地去解决它，他们是**靠采集设计避免**的。
- FEAL 只用已知数据就能压低已知样本的能量、间接把未知推到高能量区，**完全符合我的盲测协议**。
- 开集专用损失（DCEL+FEAL）在特征提取器之上还带来 **+10 AUROC**，说明"只改特征不改损失"是不够的。

**局限**
- 阈值用训练 batch 的 EMA 统计量，而非独立验证集；β 的选取依据没交代。
- 能量对齐是"把已知钉在 E0"，本质仍是压实类内，对"未知恰好落在两个类之间"没有机制性保障。

## 3. 董浩，《5G 移动设备射频指纹提取与识别研究》，东南大学硕士学位论文，2024

**内容**：5G PRACH 上的 RFF。DCTF（多通道/单通道、按索引号/按组号）+ 频域特征（去低频）
+ 联合特征。系统章节分析了 I/Q 失衡、直流偏置、载波频偏。

**与我们最相关的两段**

**(a) 发射机 I/Q 失衡的建模与估计（5.2.1）**

```
y(t) = [ζ·x(t) + (1−ζ)·x*(t)] ⊗ h(t) + ω(t)
ζ = [1 + (1+g)e^{jφ}] / 2          g 增益失衡、φ 相位失衡
```
利用**标准参考前导 x(n)** 和预处理后的实测 y(n)，构造
`Γ = (1/N)Σ y(n)x*(n)`，再配合 `c = Σ[(h⊗x)x*]`、`γ = Σ[(h⊗x*)x*]`，得到估计
`ζ̂ = (Γ − γ)/(c − γ)`。

这与我用的 `noncirc = |E[z²]|/E[|z|²]` 是同一个物理量，但 **ζ 是带相位信息的复数、
而且是对着已知参考序列解出来的**，比我的标量更干净。

**(b) 关键警告：ζ 强烈依赖前导索引号**

论文原文："不同索引号对应的PRACH 信号计算出来的失衡参数ζ 是不相同的……设备的失衡参数与
索引号出现高度相关性"，因此作者采用**基于索引号的识别结构**（每个前导索引单独建模）。

这一点是**对我方案的直接冲击**：我的 `noncirc` 也有同样的索引依赖，而我只在**划分**上做了
根序列分层，**没有在特征层面去除索引依赖**。

单特征性能：I/Q 失衡 7 类 65.40%（决策树），直流偏置 50.29%（SVM）。
（注意这是 7 类闭集准确率，不能和我的二分类 AUROC 直接比。）

## 4. 殷健，《5G 终端射频指纹与接入安全研究》，东南大学硕士学位论文

方法论上对我们的开集评测帮助有限。

## 6. 据此要改的六件事（按性价比）

1. **把 `noncirc` 换成 ζ**：用 139 点频域尾巴估出前导索引（只有 8 个根，很便宜），
   构造标准参考 x(n)，按 `ζ̂=(Γ−γ)/(c−γ)` 解出复数 ζ，取实部/虚部两维。
2. **处理 ζ 的索引依赖**：在已知训练集上按索引估 ζ 的条件均值并减掉（等价于论文的"按索引号
   建模"），或者把索引当作分层变量做条件打分。这是董浩那篇最重要的提示。
3. **把中心损失换成 maxmin**（`CE + 0.5·d_max/d_min`）：我只压了类内，缺类间。
4. **加 FEAL**：`mean((E(z)−E0)²)`，只用已知数据，符合盲测协议，消融里值 +5.4 OSCR。
5. **马氏距离改到低维**：在 7 维余弦/logit 空间算每类马氏，而不是 512→64 维。
   我在固定误拒率 5% 下测得 maha 最强（0.693），低维化可能进一步稳。
6. **DCTF 作为额外输入通道**：`D[n]=y[n]y*[n+L]` 天然消 CFO，成本很低。

## 7. 动手验证的结果（第 1、2 条）

按第 6 节做了 1 和 2，两条结论都是否定的，但都值得记下来。

### 7.1 索引依赖：对我的统计量不存在

`analysis/index_debias.py`。同一套 test / unknown_test，按前导根分组后分别算，再与汇总结果比：

| 统计量 | raw AUROC | 组内 AUROC | 去偏后 AUROC | 索引膨胀 |
|---|---:|---:|---:|---:|
| `noncirc` = \|E[z²]\|/E[\|z\|²] | 0.892 | **0.892** | 0.891 | **0.000** |
| `iq_imb_db` | 0.533 | 0.533 | 0.534 | 0.000 |

8 个前导根**逐个单独算**，AUROC 落在 0.854–0.914，没有哪个根异常。

也就是说，董浩论文里的索引依赖是**基于参考序列的 ζ̂ 估计**带来的，不是物理量本身——
`noncirc` 是个比值，对传的是哪条 ZC 序列不敏感。**所以不需要按索引建模，也不需要去偏。**

### 7.2 复数化：相位不是额外信息

`analysis/complex_impropriety.py`。把 `noncirc` 扩展成复数量 κ = E[z²]/E[\|z\|²]，检验相位是否
携带额外交互信息：

| 特征 | AUROC |
|---|---:|
| \|κ\|（= noncirc） | **0.892** |
| Re κ | 0.533 |
| Im κ | 0.435 |
| arg κ | 0.272 |
| (Re, Im) 二维逻辑回归（5 折） | 0.643 |
| 到最近已知设备中位点的距离 | 0.455 |

各设备的中位 κ：

```
UE17  (+0.0065, +0.0020)   |κ|=0.0158     model2 (-0.0076, +0.0083)  |κ|=0.0123
UE9   (+0.0081, +0.0019)   |κ|=0.0084     model5 (-0.0051, -0.0073)  |κ|=0.0101
UE12  (+0.0048, +0.0018)   |κ|=0.0060     model9 (-0.0078, -0.0020)  |κ|=0.0091
model1(+0.0020, +0.0010)   |κ|=0.0054     UE20   (-0.0009, +0.0020)  |κ|=0.0028
```

**只有幅度有用，相位是噪声。** 二维方向确实分出两族（实部正/负），但作为"离已知多远"的
开集分数反而更差（0.455）——因为 UE20 在二维平面上落在已知点云内部。

结论：继续用标量 `noncirc`，不要换复数 ζ。

### 7.3 两条路线关闭后的去向

1、2 关闭 → 剩余可做的是 **3（maxmin 损失）+ 4（FEAL）+ 5（低维马氏）+ 6（DCTF）**。
其中 3、4 是唯一被论文消融量化过的改动（UAV 那篇：+DCEL +FEAL 在特征提取器之上再 +10 AUROC）。
